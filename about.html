The studio

Made by a game developer.

Northbound Games is a game studio, and I'm the game developer behind it. As the game studio of SideQuestDigital, I make polished games that start the moment a page loads and play well on whatever screen you have. This site is the portfolio.

Everything here is built in-house: the code, the art and the sound. No downloads, no accounts, and keyboard, mouse, touch and game controllers all work.

In development

Deadzone

The studio's biggest project: a 3D first-person shooter built for the browser. The offline edition on this site has bot matches on six maps, free roam and the training range. Online multiplayer is part of the full version.

How it's made

Built for the browser

No engines or plugins for the arcade games. Just the web platform, used carefully.

Code

Plain JavaScript on the Canvas 2D API. Every game shares one small engine for input, effects and scoring.

Art

Every scene, character and effect is drawn in code, so nothing needs to download before you play.

Sound

Each sound effect is synthesized live with the Web Audio API. There are no audio files at all.

Deadzone

Built with Three.js for 3D rendering and the Rapier engine for physics, ragdolls and movement.
